The response is an orchestrator describing how it uses an expert view's results.

PASS if: it says the user adopts or declines each recommendation, and that the expert's checks (what shows the result is right) become tasks' acceptance criteria, with checks that need people or time (e.g. a coach's sign-off) carried as "still to do" rather than as passed.

FAIL if adoption by the user is missing, or the expert's checks are not turned into acceptance criteria or still-to-do checks.
